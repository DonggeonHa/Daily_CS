# Daily_CS v2 UI Binding Contract

`web/assets/app.js`, `web/assets/api.js`, and `web/assets/auth.js` are owned by `/root/v2_app_integration`. This document records the stable DOM IDs and payload shapes exposed by the retained HTML/CSS/render lane.

## Auth Shell

- `#auth-shell`, `#workspace`
- `#login-form`, `#login-email`, `#auth-status`
- `#local-logout`, `#global-logout`, `#session-label`
- Production builds must use Supabase PKCE with `sessionStorage` and `/Daily_CS/auth/callback.html`.
- Anonymous state must not request or render lesson metadata, categories, schedule snapshots, drafts, trash, or search indexes.

## Main Tabs

Buttons use `.tab[data-view]` with values:

- `reader` shows `#reader-view`
- `admin` shows `#admin-view`
- `ops` shows `#ops-view`

The integration layer should toggle the `hidden` attribute and `aria-current`.

## Reader Controls

- Today: `#reader-today` calls `reader.today`
- Search form: `#reader-search-form`
- Search input: `#reader-search` calls `reader.search`
- Category filter: `#reader-category`
- Date picker: `#reader-date`
- Date open: `#reader-open-date` calls `reader.today` for one date or `reader.history` for ranges if implemented
- Status: `#reader-status`
- Render target: `#lesson-paper`
- Result list: `#reader-list`
- Count: `#reader-count`

Reader data is private owner API data. Do not fall back to static JSON.

## Admin Catalog

- Search: `#admin-search`
- State filter: `#admin-state` values: empty, `draft`, `published`, `trash`
- Catalog target: `#admin-list`
- New draft: `#new-draft` calls `lesson.create`
- Bulk publish: `#bulk-publish` may call `lesson.publish` per selected item
- Bulk trash: `#bulk-trash` may call `lesson.bulkUpdateState` with state `trash`, or `lesson.moveToTrash` per selected item if the backend requires item-level locks

Catalog items should carry selected lesson IDs in controls generated by app integration.

## Editor Fields

Hidden row state:

- `#editor-id`
- `#editor-draft-revision`
- `#editor-published-revision`
- `#editor-state`

Lesson summary fields:

- `#editor-title`
- `#editor-legacy-id`
- `#editor-summary`
- `#editor-category`

Structured document fields:

- `#editor-document-id` maps to structured `document.id`
- `#editor-order` maps to `document.order`
- `#editor-week` maps to `document.week`
- `#editor-track` maps to `document.track`
- `#editor-level` maps to `document.level`
- `#editor-version-note` maps to `document.versionNote`
- `#editor-keywords` comma-separated `document.keywords`
- `#editor-question`
- `#editor-explanation` newline-separated array
- `#editor-comparison-headers` comma-separated `document.comparison.headers`
- `#editor-comparison-rows` newline rows, pipe-separated cells
- `#editor-example-description`
- `#editor-example-code`
- `#editor-example-language`
- `#editor-answer`
- `#editor-pitfalls` newline-separated array
- `#editor-followups` newline rows, pipe-separated `question | answer`
- `#editor-quiz-question`
- `#editor-quiz-choices` newline-separated array
- `#editor-quiz-answer-index` one-based UI value, convert to zero-based `document.quiz.answerIndex`
- `#editor-quiz-explanation`
- `#editor-sources` newline rows, pipe-separated `title | url | note`

Markdown document fields:

- Radio group `name="doc-mode"` values: `structured`, `markdown`
- `#structured-editor`
- `#markdown-editor`
- `#editor-markdown` maps to `{ markdown }`

Save payload for drafts should match `lesson.saveDraft`:

```json
{
  "id": "uuid",
  "expectedRevision": 3,
  "title": "Updated title",
  "category": "database",
  "documentKind": "structured",
  "document": {}
}
```

Do not store private lesson content in `localStorage`. Draft state belongs on the server.

## Editor Actions

- Submit `#editor-form`: `lesson.saveDraft`
- `#publish-one`: `lesson.publish`
- `#unpublish-one`: `lesson.unpublish`
- `#duplicate-one`: `lesson.duplicate`
- `#restore-trash-one`: `lesson.restoreTrash`
- `#trash-one`: `lesson.moveToTrash`
- `#purge-one`: `lesson.purge`
- `#json-preview`: render current payload into `#json-output` without persisting
- Status: `#editor-status`

## History And Diff

- Revision select: `#revision-select`, populated by `revision.list`
- Restore selected revision: `#restore-revision`, calls `lesson.restoreRevision`
- History list: `#history-output`
- Diff output: `#diff-output`
- Preview target: `#preview-output`

Use `revision.get` before restore if the UI needs to display immutable document details.

## Schedule And Mail

- `#schedule-start` comes from `settings.get`
- `#schedule-hour` maps to `settings.update.sendTime` as `HH:00`
- `#mail-paused` maps to `settings.update.mailPaused`
- `#schedule-revision` stores expected settings/schedule revision for optimistic lock
- `#schedule-override-date`
- `#schedule-override-mode` values: `auto`, `lesson`, `empty`
- `#schedule-override-lesson-id`
- `#save-schedule`: `settings.update`
- `#save-override`: `schedule.setOverride`
- `#rebuild-schedule`: `schedule.rebuildFuture`
- `#send-test-mail`: `mail.enqueueTest`
- `#ops-status`

## Import, Export, Restore

- `#export-json`: `export.create`
- `#backup-json`: owner-triggered backup/export display if supported, otherwise `export.create`
- `#restore-backup`: `backup.restore`
- `#import-json`: JSON textarea
- `#preview-import`: `import.preview`
- `#commit-import`: `import.commit`
- `#import-expected-hash`: `expectedExportHash`
- `#json-output`: JSON result display

`import.commit` must use the validated hash from `import.preview`; preview alone is not an import.

## Log And Account

- `#log-output`: render `mail.status`
- `#account-output`: render safe account/dashboard metadata from `dashboard.get` or `settings.get`

No owner email, secrets, raw credentials, or private content should appear here unless returned by owner-authenticated APIs and intended for owner display.
